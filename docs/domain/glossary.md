# Glossary

Alphabetical. One definition per term; if a term means different things in different contexts, qualify it with the context name.

| Term | Context | Definition |
| --- | --- | --- |
| Agent | Shared | Software actor that issues commands on behalf of a Principal within the limits of a Delegation. |
| Autonomy level | Shared | Degree of independence granted for an action: `L0 Inform`, `L1 Suggest`, `L2 Act with confirmation`, `L3 Act and notify`, `L4 Act silently`. |
| Delegation | Shared | Grant from a Principal to an Agent covering a scope of actions, an autonomy level, guardrails and an expiry. Revocable at any time. |
| Guardrail | Shared | Hard constraint on an Agent's actions (e.g. spend cap, allowed recipients). Breach blocks the action and escalates. |
| Principal | Shared | The person on whose behalf an Agent acts. |
